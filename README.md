# UOL Lost & Found Board  (Lab Task 03 - Firebase + RecyclerView, Section S)

Package: com.uol.lostfound | Java | minSdk 24 | Firebase BoM 34.18.0 + firebase-database
recyclerview:1.3.2, cardview:1.0.0

## Before you run
1. Create your own Firebase project, add an Android app with package name `com.uol.lostfound`.
2. Create Realtime Database -> Start in TEST MODE.
3. Download your `google-services.json` and REPLACE `app/google-services.json` with it.
4. Open the project in Android Studio, Sync, Run.

`app/google-services.json` is listed in .gitignore (do not push it to GitHub),
but keep it inside the ZIP you upload to SLATE.
